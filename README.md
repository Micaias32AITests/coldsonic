# Coldsonic

This is a music play made for I, me and myself. It may not really suit you, and
that is the intent.

I only really wanted a player that didn't ship electron, but apparently that is
too hard in 2026.

## Features

I'll fill this as i go. But right now you can't even register a music library

## Building from Source

Clone the repo and `cargo build --release`? if it doesn't work check if there is
a `flake.nix`. that probably solves it

## AI Disclosure

_TLDR: Minimal AI on code (and removing AI as I can) and NO AI on other parts_

I did use AI for the "prototype" of this project. I actually started this as a
test of what I could do with AI. But then it became a place to learn GPUI. And I
learned a lot on this.

Since then I have been rewrinting almost the full project to the GPUI
architecture and trying to do it all by hand (though sometimes I copy paste some
stuff from a chat.) I cannot guarantee that all the code on the project is
AI-free, but I do now make sure that code that was taken from an LLM is marked
as such.

What i can say is any songs, art, and things of that nature here were all made
by humans. And I will keep it that way. AI can be usefull for code sometimes,
but I don't want it touching the parts of my life where i want human-made
products.
